# 🖥️ LATCHI IPTV — نسخة الحاسوب

نسخة الحاسوب الرسمية من **IPTV LATCHI DZ** — نفس واجهة التلفاز، نفس الهوية البصرية،
نفس نظام التحقق.

## ✨ المزايا
- 🎨 واجهة تلفازية كاملة: كحلي داكن + ذهبي، تنقل بالأسهم/Enter/Esc + الفأرة
- 🔑 الدخول: كود التفعيل عبر السكريبت (نفس نظام أندرويد) أو رابط M3U مباشر
- 📡 البث المباشر (Xtream + M3U) مع فئات وبحث
- 🎬 الأفلام والمسلسلات ببوسترات عمودية 2:3 — 6 بالصف (نفس أندرويد)
- 📺 المواسم والحلقات مع الاستئناف
- ⭐ المفضلة + ⏯ متابعة المشاهدة (استئناف من موضع التوقف)
- ▶️ مشغل hls.js بتحكم تلفازي كامل (أسهم = تقديم/صوت، F = ملء الشاشة، Esc = رجوع)

## 🏗️ البناء
GitHub Actions (`.github/workflows/build-desktop.yml`):
- يدوي (workflow_dispatch) → مخرجات Artifacts
- عند الوسم `v*` → GitHub Release تلقائي

```bash
npm install
npm start        # تشغيل للتطوير
npm run dist     # بناء محلي (NSIS + Portable)
```

## 🔒 الهوية
كل الصور من ورقة المرجع الأساسية لصاحب التطبيق (نفس قاعدة مستودع أندرويد).
